# 연구 주제 (2026-10-22 확정)

**게임 룰로 정의된 용어 중심 언어 구조에 대한 언어 모델 적용 논의**
**— 디지몬 카드 게임을 중심으로 —**

## 1. 문제의식

카드 게임의 카드 텍스트는 겉보기에는 한국어 문장이지만, 실제로는 **종합 룰이 정의한 용어**로 짜인 제한 언어입니다.
- 【등장 시】, 「~했을 때」, 「~하는 것으로」, 「~라면」, 《블로커》, 「진화원」, 「배틀 에어리어를 벗어날 때」 같은 표현은 일상어의 뜻이 아니라 룰 조항이 정한 뜻(유발 조건, 임의 처리 조건, 처리 조건, 키워드 효과, 영역, 즉시형 효과)으로 읽어야 합니다.
- 같은 낱말이 일상어와 다르게 쓰입니다. 예: 「등장」 ≠ 「부화」, 「소멸」 ≠ 「파기」 ≠ 「덱 아래로 되돌림」, 「사용」 ≠ 「발휘」.
- 판정(룰 질문의 답)은 이 용어들의 정의와, 용어가 적용되는 **상황**에서 나옵니다.

반면 이용자의 질문은 일상어·구어·은어로 들어옵니다(「바황드 조그 진화시 쓸수있어?」). 이 연구는 범용 언어 모델을 이런 **용어 중심 언어**에 적용할 때 무엇이 되고 무엇이 안 되는지, 언어 모델을 어디에 두어야 하는지를 디지몬 카드 게임(한국어판)으로 실증합니다.

## 2. 연구 질문

| | 질문 | 주요 실험 |
|---|---|---|
| RQ1 | **용어 구조의 분해:** 카드 텍스트를 룰이 정의한 용어 체계(분류 15-8, 유발 조건 15-5, 처리 조건 15-6, 임의 처리 조건 15-7, 처리 단계)로 자동 분해할 수 있는가? | E1, E10, E11, E13, E17, E30 |
| RQ2 | **용어와 판정의 관계:** 용어 구조가 같으면 판정도 같은가? 판정을 정하는 것은 용어인가, 용어가 놓인 상황인가? | E19a, E42, E43, E44 |
| RQ3 | **일상어 ↔ 용어 언어의 연결:** 구어체·별명·설명이 부족한 질문을 용어로 쓰인 공식 질문에 이을 수 있는가? 언어 모델은 이 연결에서 얼마나 기여하는가? | E24, E31, E38, E39 |
| RQ4 | **언어 모델의 개입 범위:** 범용 LLM 단독, 용어 근거를 준 LLM, LLM 없는 용어 구조·검색 판정은 각각 어느 수준인가? LLM은 판정 체계의 어디에 두어야 하는가? | E3, E18, E19, E20~E23, E27, E32~E37, E41 |

## 3. 지금까지의 근거 (잠정 주장)

1. **용어 구조는 기계적으로 꽤 정확히 추출된다 (RQ1).** 룰북 15장 기준 분해의 사람 검수(300효과) 정확도는 분류 0.980 · 유발 조건 0.996 · 처리 조건 0.964 · 임의 처리 조건 0.980 · 처리 0.875입니다(E17, v4.0). 가장 약한 곳은 처리 단계 분해입니다.
2. **판정은 용어보다 상황에 달려 있다 (RQ2).**
   - 같은 효과(문구 틀 또는 룰북 구조가 같음)에 같은 것을 묻는 이전 Q&A끼리도 답이 같은 비율은 62%입니다(E44).
   - 상황 조건을 풀면 같은 효과 근거의 정확도는 54%로 떨어집니다(E43).
   - 효과 네트워크(SNA) 클러스터 다수결은 62~73%에 그쳤습니다. 판정 쟁점은 처리보다 타이밍·유발 조건을 따라 갈립니다(E42).
3. **범용 LLM은 용어 근거가 있어야 믿을 만하다 (RQ4).** 공식 Q&A 200문항에서 Claude 단독 89.0%, 문구 검색 근거를 주면 98.0%, 판정 도우미 용어 구조 근거를 주면 98.0%입니다(E18, McNemar p<0.001). 용어 근거 없이 LLM이 틀리는 지점은 용어의 룰상 정의입니다(예: 「진화원 효과에 《X》를 가진 카드」).
4. **LLM 없는 판정은 「선택적」으로만 신뢰할 수 있다 (RQ4).** 용어가 같은 공식 선례, 정리된 룰 쟁점, 근거 신호를 결합한 엔진, 의미 검색으로 최신 팩 질문의 47~51%를 98.5~98.6% 정확도로 판정합니다(시간 분할, E32~E37, E44). 나머지는 판정 보류 후 사람(심판) 확인으로 돌립니다(E41).
5. **언어 모델이 가장 잘하는 일은 「판단」보다 「번역(연결)」이다 (RQ3).** 구어체 질문을 공식 질문에 잇는 검색에서, 미세 조정한 문장 모델 + 문자 2-gram 융합의 1위 적중률은 구어체 0.874, 공식 문장 0.917입니다(E31). 설명이 부족한 질문은 0.540에서 0.644로 올랐습니다(E38). 공동체 별명(「바황드」 = 바이러스종 황제드라몬: 드래곤 모드)은 사전으로 공식 용어에 대응시켰습니다(E39).
6. **규칙 실행 엔진(DCGO)은 정확하지만 범위가 좁다.** 실행 시험의 정확도는 77%, 판정 범위는 11%였습니다(E20~E23). 용어의 의미를 코드로 다 옮기는 비용이 큽니다.

## 4. 목차 초안

1. 서론 — 용어 중심 언어와 범용 언어 모델, 연구 질문
2. 관련 연구 — 제한 언어(controlled language)·도메인 용어, 법률·규정 텍스트 분석, 게임 룰 형식화, 검색 증강 생성(RAG), 선택적 예측(selective prediction)
3. 자료 — 카드 텍스트 3,852종, 종합 룰 Ver.4.3 1,138조항, 공식 카드 Q&A 5,308문항, 규칙 해설 739문항, 커뮤니티 질문(로컬 전용)
4. 용어 구조의 형식화(RQ1) — 룰북 15장 기반 분해 체계, 정답셋과 검수자 일치도
5. 용어와 판정(RQ2) — 같은 효과·같은 상황의 판정 일관성, 효과 네트워크 분석, 룰 쟁점 계층
6. 일상어와 용어의 연결(RQ3) — 구어체·모호 질문 시험셋, 정규화·별명 사전·검색 모델 학습과 융합
7. 언어 모델의 자리(RQ4) — LLM 단독·근거 제공·LLM 없음 비교, 시간 분할 선택적 판정, 초안-심판 확인 구조
8. 논의 — 용어 중심 언어에 언어 모델을 적용하는 원칙: 용어 정의는 사람이 정한 체계로, 연결은 모델로, 판정은 근거가 있을 때만
9. 한계 — 한 게임·한 언어, 공식 Q&A 분포 편향(반복 질문), 정답셋 규모, 커뮤니티 데이터의 이용 제약
10. 결론
