# GPU 검색 모델 결과 (E31 후속)

모델: jhgan/ko-sroberta-multitask, MultipleNegativesRankingLoss, 3 에폭, bs 16, lr 2e-5. 학습 쌍 5,981개(긍정 쌍 + 어려운 부정, 구어체 증강 확률 0.7).
평가 세트(`colloquial_test.json` 200문항)와 최신 팩 Q&A는 학습에서 제외. 구어체 평가는 정답이 말뭉치에 있는 87문항만 씀.
환경: GTX 1660 SUPER 6GB, 학습 시간 약 30분(기본), 약 33분(정규화). GPU 메모리 사용량 약 5.4GB.

## 결과 (recall@k, 학습 후 모델 대 브라우저 2-gram)

| 평가 | 실험 | recall@1 | @3 | @10 |
|---|---|---|---|---|
| 구어체 (n=87) | 브라우저 2-gram | 0.713 | 0.874 | 0.931 |
| 구어체 (n=87) | 학습 전 (base) | 0.609 | 0.701 | 0.713 |
| 구어체 (n=87) | **학습 후 base** | **0.828** | 0.897 | 0.954 |
| 구어체 (n=87) | 학습 후 base_norm | 0.828 | **0.908** | **0.966** |
| 최신 팩 공식 질문 (n=314) | 브라우저 2-gram | 0.873 | 0.959 | 0.990 |
| 최신 팩 공식 질문 (n=314) | 학습 전 (base) | 0.876 | 0.901 | 0.930 |
| 최신 팩 공식 질문 (n=314) | **학습 후 base** | **0.895** | 0.933 | 0.990 |
| 최신 팩 공식 질문 (n=314) | 학습 후 base_norm | 0.857 | 0.908 | 0.994 |

`base_norm`은 `--norm`(질문과 말뭉치를 qnorm으로 정규화)을 적용한 실험이에요.

## 결론
1. **구어체에서 학습 후 모델이 브라우저 2-gram을 넘어요.** recall@1이 0.713에서 0.828로 11.5%p 올라요. 표본이 87개라 차이는 약 10문항 수준이에요. 이 기준은 충족해요.
2. **정규화(`--norm`)는 도움이 되지 않아요.** 구어체에서는 @3과 @10이 1문항 안팎 좋아졌을 뿐이에요. 최신 팩 공식 질문에서는 @1이 0.895에서 0.857로 떨어져서(약 12문항), 전체로는 손해예요. 기본 설정(`base`)을 쓰는 것이 낫다고 판단해요.
3. 최신 팩 공식 질문에서 @3은 브라우저(0.959)가 여전히 높아요. 학습 후 모델은 0.933이에요.

## 이상한 점 / 코드 변경
- 처음에 bs 32로 돌렸는데, GPU 메모리가 6GB에 가까워지면서 스텝당 시간이 13초에서 325초까지 늘었어요(Windows의 메모리 스왑으로 보임). 이 실행은 중단했고, bs 16으로 다시 돌렸어요. 스텝당 시간은 1.4~2.6초로 정상이었어요.
- `train_retriever.py`는 수정하지 않았어요.
- 구어체 평가 정답 문항이 200개 중 87개뿐이에요. 스크립트가 정답 묶음(이유 묶음과 답의 방향)이 말뭉치에 있는 문항만 세기 때문이에요. 이 점은 이후 평가 세트를 정리할 때 확인해야 해요.
- 모델 가중치는 커밋하지 않았어요(`.gitignore`).

## 브라우저용 학생 모델 (증류, 미통과)
- 교사: 학습 후 `retriever_base` (ko-sroberta). 학생: 해시 2·3-gram → 임베딩 평균(차원 128) → 선형층(교사 차원 768). 3만 문장으로 코사인 손실 학습(30 에폭).
- 구어체 recall@3 0.552 (교사 0.897의 62%, 기준 95%에 미달). 최신 팩 recall@3 0.939 (교사 0.933과 비슷).
- 결론: 글자 조합만으로는 구어체의 의미를 잇지 못함. 구조를 키우거나 서버 방식으로 바꿔야 함.

### 작은 트랜스포머 학생 (미통과)
- 학생: BERT 구조 인코더 (차원 256, 4층, 머리 4개, 무작위 초기화, 약 11.6M 파라미터), 교사와 같은 토크나이저, 평균 풀링 → 선형층(768). 3만 문장으로 코사인 손실 학습(40 에폭, AdamW, OneCycle).
- 구어체 recall@1 0.678 / @3 0.736 / @10 0.851 (교사 @3 0.897의 82%, 기준 95%에 미달). 이전 글자 n-gram 학생(@3 0.552)보다 올랐어요.
- 최신 팩 recall@1 0.860 / @3 0.933 / @10 0.990 (교사 @3 0.933과 같음).
- 코드: `train/distill_tf.py`. 가중치(`student.pt`)는 커밋하지 않아요.
- 코드: `train/distill_retriever.py` (해시 함수는 브라우저 JS와 같은 FNV-1a 방식). 학생 가중치는 `.gitignore`로 제외.
